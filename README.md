# Math Quiz App

Простое интерактивное десктопное приложение для тренировки базовых арифметических навыков на время. Программа генерирует случайные примеры на четыре основных математических действия, проверяет ответы пользователя в реальном времени и отсчитывает время до конца раунда.

## Особенности игры

* **Случайная генерация:** каждый раунд предлагает новые числа для сложения ($+$), вычитания ($-$), умножения ($\times$) и деления ($\div$).
* **Динамический таймер:** на решение всех примеров дается фиксированное время (30 секунд).
* **Визуальное предупреждение:** когда до конца игры остается **5 секунд или меньше**, фоновое поле таймера окрашивается в **красный цвет**, сигнализируя о нехватке времени.
* **Автоматическое автозаполнение:** в случае проигрыша игра автоматически показывает правильные ответы во всех полях.
* **Интерфейс на WinForms:** ввод чисел через удобные счетчики (NumericUpDown), исключающие ввод некорректных символов.

## Игровой процесс и условия

### Начало игры
Нажмите кнопку **"Start the quiz"**, чтобы запустить обратный отсчет и сгенерировать новые математические выражения. Во время игры кнопка становится неактивной.

### Победа
Если вы успеваете правильно решить все четыре примера до истечения таймера:
1. Игра останавливается.
2. Появляется всплывающее окно: **"You got all the answers right! Congratulations!"**
3. Кнопка старта снова становится активной для начала нового раунда.

### Проигрыш
Если таймер доходит до `0 seconds`:
1. Появляется всплывающее окно: **"Sorry! You didn't finish in time. Fill in the answers."**
2. Приложение автоматически подставляет правильные ответы во все поля, чтобы вы могли провести работу над ошибками.
